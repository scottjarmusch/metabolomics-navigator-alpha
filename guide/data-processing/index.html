Processing analytical data

Process spectra, extract features and quantify targets.

How to choose a resource

MS measurements need processing before comparison: detect signals, correct or align spectra, and assemble quantitative tables. A feature is not necessarily a single identified metabolite.

Check your acquisition mode and file format, the quality-control steps available, and whether you prefer a graphical or scripted workflow.
