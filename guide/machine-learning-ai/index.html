Machine learning and AI in MS metabolomics

Understand what a model predicts, what evidence it needs and how to assess its output.

How to choose a resource

AI is an umbrella term; machine learning is one family of AI methods. Tools can combine several approaches. Start with your scientific task, then check the input data, model version and evidence behind the prediction.

Separate training a model from using pretrained weights. Hardware, licensing and data-transfer requirements can differ. Record the model and version, check performance on relevant chemistry and acquisition conditions, and treat predicted structures or associations as hypotheses.

Terms you will encounter

Predictive machine learning

Learns a relationship from examples, such as molecular structure to fragmentation spectrum or MS/MS to chemical class. Evaluate the specific prediction task and model applicability.

Spectral representation learning

Learns numerical representations of spectra for tasks such as similarity search. DreaMS uses self-supervised learning; a similar representation is not proof of identical structure.

Generative models

Generate candidates, such as molecular structures or fragmentation graphs. Generation does not establish that a proposed molecule is present in the sample.

Foundation models

Broadly pretrained models adapted to multiple downstream tasks. This describes training and reuse, not a guarantee of reliability for every instrument or sample type.

Agentic AI

A model selects or coordinates analysis tools over multiple steps. Inspect the actual tools, parameters, intermediate evidence and human review points. An agent can call both learned models and conventional software.

Workflow automation

Runs processing steps automatically. Automation alone does not imply learned inference or an AI agent. Everything Bagel is currently documented here as automated feature finding; use within an agentic workflow does not change that classification.

These descriptions overlap. They describe how a method works, while the catalogue’s scientific functions describe what it helps you do.

Tools & resources

5 entries

  • ICEBERG

    Open source

    ICEBERG is a two-stage neural network that predicts mass spectra from molecular structures. It can rank candidate structures against a spectrum for metabolite annotation.

    Predict spectra and rank candidate structures↗

  • MSNovelist

    Free for academic use

    A SIRIUS-integrated de novo structure-generation method that proposes molecular structures from a predicted molecular formula and CSI:FingerID fingerprint when database search is insufficient.

    Generate molecular-structure candidates↗

  • CSI:FingerID

    Free for academic use

    A SIRIUS-integrated machine-learning method and webservice for predicting molecular fingerprints from MS/MS data and ranking candidate structures from molecular-structure databases.

    Predict fingerprints for structure-database searches↗

  • CANOPUS

    Free for academic use

    A SIRIUS-integrated machine-learning method and webservice for predicting compound classes directly from high-resolution MS/MS data without requiring an exact database structure match.

    Predict compound classes↗

  • PeakDecoder

    Open source

    Use machine learning to support metabolite identification and error-rate estimation in multidimensional LC-IM-MS-DIA data.

    Detect and annotate features in DIA data↗
