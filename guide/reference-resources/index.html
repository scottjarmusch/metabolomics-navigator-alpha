Sharing data and reference knowledge

Preserve data and connect reference evidence.

How to choose a resource

Repositories preserve experimental files, reference spectra support annotation, and knowledgebases connect molecular evidence to its reported context. These resources serve different purposes, but all depend on clear metadata and traceable evidence.

Distinguish depositing a dataset from preparing a reference spectrum or contributing a biological annotation. Keep the source files, identifiers, and supporting evidence connected.
