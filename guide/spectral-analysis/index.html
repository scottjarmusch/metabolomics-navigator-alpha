Exploring spectral relationships

Find relationships and patterns in spectra.

How to choose a resource

Tandem mass spectra contain fragmentation information that can help investigate related molecules. Molecular networking organizes spectra by similarity, while a query language can find spectra containing a specified pattern. These approaches help prioritize signals for closer inspection.

Decide whether you need to explore relationships across a dataset or test a specific spectral pattern. Similarity or a query match alone does not establish a complete structure.

Analytical strategies

Understand the method, then choose its software implementation.

Feature-Based Molecular Networking (FBMN)A strategy that combines aligned LC-MS feature abundances with MS/MS spectral similarity to explore quantitative molecular families while retaining chromatographic feature identity.Ion Identity Molecular Networking (IIMN)A strategy extending feature-based molecular networking with MS1-derived ion relationships, linking candidate ion species of the same molecule alongside MS/MS spectral-similarity edges.

Tools & resources

17 entries

  • GNPS

    Free web service

    A web-based mass-spectrometry ecosystem for molecular networking, spectral-library search, repository-scale search, interactive visualization, knowledgebase curation, and public-data integration.

    Molecular networking & libraries↗

  • GNPS2 Classical Molecular Networking

    Free web service

    GNPS2 workflow for organizing MS/MS spectra into molecular families using pairwise spectral similarity and spectral-library searching.

    Spectrum-centric molecular networking↗

  • GNPS2 Feature-Based Molecular Networking workflow

    Free web service

    Dedicated GNPS2 workflow that combines an aligned LC-MS feature table with MS/MS spectra to build quantitative molecular networks.

    Quantitative feature-based networking↗

  • MassQL

    Open source

    An open-source, instrument-independent query language and software ecosystem for searching mass-spectrometry data using reusable MS1, MS/MS, chromatographic, and ion-mobility patterns.

    Chemical-pattern queries↗

  • matchms

    Open source

    Build Python workflows for spectral cleaning, metadata harmonization and MS/MS similarity scoring.

    Clean and compare MS/MS spectra↗

  • Spec2Vec

    Open source

    Compare tandem mass spectra using embeddings learned from recurring peaks and neutral losses.

    Learned spectral similarity↗

  • MS2DeepScore

    Open source

    Estimate molecular structural similarity from pairs of tandem mass spectra.

    Predict structural similarity↗

  • MS2LDA

    Source available with restrictions

    Find recurring patterns of fragments and neutral losses across tandem mass spectra.

    Discover recurring substructure motifs↗

  • MolNetEnhancer

    Source available with restrictions

    Combine molecular networking, substructure motifs and chemical classifications into annotated networks.

    Combine network annotation evidence↗

  • MolNetInvert

    Open source

    Create metadata-based molecular networks from GNPS networks or feature tables to explore how metabolites are distributed across sample groups.

    Explore metadata-based molecular networks↗

  • PostMN MassQL

    Free web service

    Run MassQL chemical-pattern queries directly on consensus spectra produced by GNPS molecular networking.

    Query processed networking spectra↗

  • Multi-step MassQL

    Free web service

    Apply a predefined sequence of MassQL queries to GNPS2 networking spectra to investigate bile acids and their isomers.

    Bile-acid query sequences↗

  • MassQL Playground

    Free web service

    Browser-based MassQL query editor and runner for exploring fragmentation patterns in local mass-spectrometry files.

    Query local spectra in the browser↗

  • GNPS2 MassQL Analysis

    Free web service

    Hosted interface for exploring MS/MS spectral libraries with MassQL and using LLM assistance to draft or explain queries.

    Explore library queries with assistance↗

  • TinyMass

    Free web service

    Hosted utility for sharing mass spectra through reusable spectrum identifiers in the GNPS2 ecosystem.

    Share an individual spectrum↗

  • MetGem

    Open source

    Local desktop generation and exploration of MS/MS similarity networks and two-dimensional spectral projections.

    Local MS/MS network generation↗

  • Cytoscape

    Open source

    Desktop network visualization and analysis for exploring MS molecular networks alongside feature annotations and sample metadata.
