Overview

Pan-ReDU is the current expansion of ReDU for harmonizing controlled sample metadata and indexing public mass-spectrometry files across repositories including MetaboLights, Metabolomics Workbench/NMDR, and GNPS/MassIVE. It links harmonized metadata with persistent run identifiers, raw-file access, and indexed MS/MS searching so researchers can discover, download, co-analyze, and contextualize public metabolomics data across repository boundaries.

Also known as: ReDU, Reanalysis of Data User Interface

What can this tool do?

Metadata-based contextualizationRepository-scale spectral search

Common uses

  • Find public metabolomics files by harmonized organism, biospecimen, disease, phenotype, and other controlled metadata.
  • Discover and download files across MetaboLights, Metabolomics Workbench/NMDR, and GNPS/MassIVE using a common metadata layer.
  • Contextualize MASST/FASST spectral matches across repositories and prepare public datasets for reanalysis or co-analysis.
  • Assemble a public-data cohort using sample metadata, then retrieve files for a documented reanalysis.

Scope and considerations

Designed for

  • Pan-repository discovery, contextualization, and reuse of public mass-spectrometry data using harmonized metadata and file identifiers.

Not designed for

  • Replacing primary repository records or correcting every missing or inconsistent sample annotation.

Important requirements

  • Repository records need sufficiently structured sample information to support the desired query.

Considerations

  • Metadata completeness and harmonization quality remain dependent on the information available in the source repositories and historical submissions.
  • Repository coverage and indexed file counts evolve as Pan-ReDU is updated.
  • Save the selected file identifiers and harmonized metadata with the analysis; harmonization does not make experimental strategies equivalent.
