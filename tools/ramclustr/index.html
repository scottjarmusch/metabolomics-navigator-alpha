Overview

RAMClustR groups features using retention and abundance relationships. Its workflow supports feature filtering, QC normalization and spectral export for subsequent annotation.

What can this tool do?

Spectral deconvolutionAdduct and isotope grouping

Common uses

  • Reduce redundant features into compound-related clusters.
  • Export reconstructed spectra for library matching.

Scope and considerations

Designed for

  • Reduce redundant features into compound-related clusters.

Not designed for

  • Treating every cluster as a pure, independently identified metabolite.

Important requirements

  • A feature table with m/z, retention time and sample information, or supported XCMS objects.

Considerations

  • Correlated coeluting compounds can merge; review clustering thresholds and reconstructed spectra.
