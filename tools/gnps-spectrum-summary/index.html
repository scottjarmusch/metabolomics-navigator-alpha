Overview

The spectrum-summary app displays peak and neutral-loss histograms for spectra selected through a GNPS2 network component or a list of Universal Spectrum Identifiers. It supports inspection of shared fragmentation evidence before more detailed annotation.

What can this tool do?

Interactive dashboard

Common uses

  • Inspect common fragment signals among related spectra.
  • Examine recurring neutral losses in a selected network component.

Scientific fit

Primary function

Spectral processing and comparison

Data compatibility

Inputs

Mass spectra

Outputs

Human-readable report

Input formats

Universal Spectrum Identifiers, one per line, GNPS task and network-component identifiers with node selection

Output formats

Interactive peak and neutral-loss histograms

Scope and considerations

Designed for

  • Exploratory comparison of shared fragmentation across selected MS/MS spectra.

Not designed for

  • Definitive structure identification or quantitative feature-table processing.

Important requirements

  • Accessible spectra referenced by USIs or a supported GNPS network task.
  • Selection of spectra appropriate to the scientific comparison.

Considerations

  • Shared peaks and losses support hypotheses but are not unique structural assignments.
  • Acquisition conditions, precursor selection and the chosen spectrum subset affect the summary.
  • Input controls and plots were inspected without submitting a user dataset; operational performance remains untested.
