Overview

rMSIproc adds C++ processing routines to the rMSI data model, producing processed images and peak matrices through R functions or a parameter wizard.

What can this tool do?

Peak or feature detection

Common uses

  • Extract peak matrices from imaging datasets.
  • Apply smoothing, mass alignment and calibration before spatial analysis.

Scientific fit

Primary function

Preprocessing and feature extraction

Analysis types

Spatial metabolomics

Data compatibility

Inputs

Imaging data

Outputs

Imaging data, Feature or peak table

Input formats

imzML, rMSI TAR format

Output formats

Processed rMSI TAR datasets and rMSIproc peak-matrix files

Scope and considerations

Designed for

  • MSI preprocessing with rMSI-compatible data.

Not designed for

  • Chromatographic retention-time alignment or definitive compound identification.

Important requirements

  • Working rMSI installation and compatible R/C++ toolchain.
  • FFTW support; follow platform-specific installation instructions.

Considerations

  • Check mass calibration and binning settings against the instrument resolution.
  • Keep preprocessing parameters with output matrices for reproducibility.

Access and documentation

Primary access↗

R source installation requires compatible native dependencies. The documented GUI uses RGtk2; verify installation on the target operating system before planning an analysis.
