Overview

xcms is a scriptable Bioconductor framework for processing chromatographically separated mass-spectrometry data in R. It provides algorithms for chromatographic peak detection, retention-time correction, correspondence/grouping across samples, filling missing feature intensities, and inspection of LC-MS and GC-MS datasets within reproducible analysis scripts.

Also known as: XCMS

What can this tool do?

Chromatogram buildingPeak or feature detectionRetention-time alignmentGap fillingSpectral deconvolution

Common uses

  • Build scriptable preprocessing workflows for untargeted chromatographic MS data.
  • Detect chromatographic peaks and align retention times across samples.
  • Export a feature-intensity table with sample metadata for downstream statistics after checking peak quality.

Scope and considerations

Designed for

  • Reproducible, script-based preprocessing of LC-MS and GC-MS datasets in the R/Bioconductor ecosystem.

Not designed for

  • Standalone confirmation of compound structures from chromatographic features.

Important requirements

  • R and Bioconductor plus the package dependencies appropriate to the selected xcms release.

Considerations

  • The package is code oriented rather than a standalone point-and-click workflow, so users benefit from basic R familiarity.
  • Inspect representative chromatograms and alignment diagnostics; gap filling integrates signal in an expected region and does not guarantee a true detected metabolite.
