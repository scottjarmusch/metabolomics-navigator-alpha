Metabolite annotation and identification

MS-Net

MS-Net combines annotation levels from both mass spectral libraries and in silico tools such as MS-Finder or Sirius-CSI to build a comprehensive candidate chemical space. Then, MS-Net prioritizes annotation using the molecular network and Tanimoto-based similarity with optional biosource reranking. Additionnaly it can combine positive and negative acquisition modes and add metadata to all annotated features, such as chemical ontology or database identifiers.

Overview
