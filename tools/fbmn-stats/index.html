Overview

FBMN-STATS provides an accompanying app and notebooks for downstream analysis of non-targeted LC-MS/MS feature tables. It connects data cleanup and statistical comparisons to the interpretation of molecular-network results.

What can this tool do?

Blank and contaminant filteringBatch-effect correctionUnivariate statisticsMultivariate statisticsInteractive dashboard

Common uses

  • Examine group differences and multivariate patterns in processed LC-MS/MS data.
  • Prepare statistical results for interpretation alongside molecular networks.

Scope and considerations

Designed for

  • Downstream quantitative analysis of feature-based molecular networking results.

Not designed for

  • Raw-file feature detection or definitive compound identification.

Important requirements

  • Compatible feature tables and sample metadata, including grouping and blank information where applicable.
  • Choose an interface and analysis appropriate to the study design.

Considerations

  • Legacy GNPS Quickstart exports may lack the reformatted outputs required by the current integration; maintainers recommend GNPS2.
  • Normalization, missing values, batch structure and multiple comparisons require study-specific decisions.
  • Notebooks and the web app need not expose identical operations; consult the selected interface documentation.
