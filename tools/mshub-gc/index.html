Overview

MSHub-GC separates overlapping GC-MS signals computationally. Its GNPS2 workflow produces deconvolved spectra, a quantification table and a cluster summary. These outputs support subsequent library searching and molecular networking in the GC-MS analysis ecosystem.

What can this tool do?

Spectral deconvolution

Common uses

  • Recover component spectra from overlapping GC-MS chromatographic signals.
  • Prepare quantitative and spectral outputs for downstream annotation.

Scientific fit

Scope and considerations

Designed for

  • Untargeted GC-MS processing, including volatile-metabolite studies.

Not designed for

  • LC-MS/MS feature processing or automatic confirmation of every compound identity.

Important requirements

  • GC-MS files in CDF, mzML or mzXML format, with one format used throughout the input folder.
  • The correct chromatographic time unit and a GNPS2 account.

Considerations

  • Inspect deconvolution quality and chromatographic separation before interpreting component spectra.
  • The linked paper describes the wider processing-and-networking system; the current launch page is the deconvolution workflow.
  • Do not assume support for every vendor-native file type; confirm conversion and input compatibility in the current documentation.

Access and documentation

Primary access↗Documentation↗Source repository↗

GNPS2 is openly available to the academic community. The current GNPS2 documentation asks industry users to contact the maintainers or UC Riverside Technology Transfer regarding organizational access. Workflow submission requires a GNPS2 account. The linked workflow repository is public; this hosted-service entry does not assert a license for every bundled processing dependency.
