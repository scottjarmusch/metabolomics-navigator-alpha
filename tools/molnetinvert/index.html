Overview

MolNetInvert is a desktop GUI implementing Metadata-Based Molecular Networks (MBMN). It reorganizes processed metabolomics data around selected sample metadata and can simplify network views by collapsing clusters. Metadata connections describe sample-group associations; they are distinct from MS/MS similarity or ion-identity evidence.

What can this tool do?

Network visualization

Common uses

  • Compare metabolite distributions across biological conditions or sample groups.
  • Reorganize dense networks and singleton features around metadata.

Scope and considerations

Designed for

  • Downstream exploration of processed MS metabolomics networks and feature tables.

Not designed for

  • Raw-file preprocessing or confirming compound identities from metadata connections.

Important requirements

  • GNPS GraphML with appropriate metadata, or a CSV feature table and tab-delimited sample-to-group metadata in the documented format.

Considerations

  • Missing or inconsistent sample metadata changes the resulting grouping.
  • Collapsing or filtering nodes can hide detail; retain the original network and record settings.
  • Input modes and compatibility were checked in v1.2 source; software execution was not tested.
