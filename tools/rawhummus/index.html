Overview

RawHummus summarizes chromatographic and MS-level quality measurements to help inspect system performance. It produces interactive QC reports and supports local execution; detecting a problem does not automatically correct the underlying data.

Scope and considerations

Designed for

  • Inspect LC-MS instrument logs and raw QC measurements through an R Shiny interface.

Not designed for

  • Confirming compound identity or replacing study design and scientific review.

Important requirements

  • Representative QC measurements and an R/Shiny environment for local use.
  • Supported raw QC measurements and instrument log files; consult the app instructions for instrument-specific import

Considerations

  • The documented free hosted deployment has memory limits; local execution is recommended for larger sets.
  • Thresholds are diagnostic aids, not universal acceptance criteria.
