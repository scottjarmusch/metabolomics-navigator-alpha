Compound-class prediction with CANOPUS

CANOPUS uses the molecular fingerprint predicted by CSI:FingerID and a deep neural network to assign compound classes and chemical ontologies. It is designed to provide class-level structural information for unknown metabolites, including compounds lacking matching reference spectra or database structures.

  1. Annotate the precursor formula

    Use SIRIUS to obtain a plausible molecular formula and fragmentation-tree representation for each feature.

  2. Predict the molecular fingerprint

    Run CSI:FingerID fingerprint prediction as the structural representation used by CANOPUS.

  3. Predict compound classes with CANOPUS

    Generate class probabilities and ontology assignments without requiring an exact database search for the unknown structure.

  4. Interpret class-level patterns

    Use predicted classes to summarize chemical diversity, compare groups, or prioritize unknown features for deeper structural work.

Requirements

  • High-resolution MS/MS suitable for SIRIUS/CSI:FingerID processing; CANOPUS is a webservice-backed SIRIUS feature requiring current account/license access.

Considerations

  • CANOPUS predictions are compound-class annotations rather than exact molecular structures.
  • Class probabilities and ontology depth vary by spectrum and chemical space; downstream biological interpretation should reflect prediction uncertainty.

Dührkop K, Nothias L-F, Fleischauer M, et al. Systematic classification of unknown metabolites using high-resolution fragmentation mass spectra. Nature Biotechnology 39, 462–471 (2021).

Overview

CANOPUS uses molecular fingerprints predicted from tandem mass spectra to infer hierarchical compound classes. Because it predicts class membership without requiring the exact compound to exist in a spectral or structure database, it is particularly useful for characterizing unknown metabolite features when precise structure identification is not possible. CANOPUS is currently accessed as a webservice-backed component of SIRIUS.

Common uses

  • Assign hierarchical chemical classes to MS/MS features lacking confident exact structure annotations.
  • Summarize chemical diversity across large untargeted metabolomics datasets at class level.
  • Provide structural context for features absent from spectral and molecular-structure reference databases.

Scope and considerations

Designed for

  • Compound-class prediction from accurate-mass tandem mass spectra.

Not designed for

  • Confirmation of an exact compound structure or discrimination of stereoisomers.

Important requirements

  • SIRIUS-compatible high-resolution MS/MS data and access to the SIRIUS webservice.

Considerations

  • CANOPUS predicts compound classes rather than exact structures; results should not be reported as compound-level identifications.
  • Class confidence and resolution depend on the information contained in the spectrum and the trained classification hierarchy.
  • Inspect predicted class probabilities and hierarchy alongside the spectrum; retain the SIRIUS project and class export.
