Overview

FAMetA is an R package for model-based fatty-acid metabolic analysis. The publication also describes a web application. Its workflow uses LipidMS for preprocessing and accucor for natural-abundance correction before fitting fatty-acid metabolic contributions.

What can this tool do?

Metabolic-flux estimation

Common uses

  • Investigate fatty-acid metabolic contributions in tracer experiments.

Scientific fit

Primary function

Isotope tracing and flux analysis

Data compatibility

Inputs

Isotope-tracing data

Outputs

Statistical results, Human-readable report

Input formats

Fatty-acid carbon-13 mass-isotopologue profiles prepared for the R workflow

Output formats

Fitted fatty-acid metabolic contributions and graphical summaries

Scope and considerations

Designed for

  • Model-based analysis of fatty-acid labeling.

Not designed for

  • Untargeted structure identification or unrestricted whole-network flux analysis.

Important requirements

  • Suitable carbon-13 labeling data and the R/LipidMS/accucor dependencies.

Considerations

  • Model assumptions, tracer choice and isotopologue measurement quality constrain interpretation.
