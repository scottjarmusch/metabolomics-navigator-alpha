Overview

Cytoscape displays supplied nodes, edges and associated tables. In MS metabolomics it supports inspection and presentation of molecular networks generated upstream, with styles that encode sample groups or annotations. The desktop platform and its separately installed apps have distinct capabilities; a network viewer does not itself establish spectral matches.

What can this tool do?

Network visualizationInteractive dashboard

Common uses

  • Style GNPS networks using study metadata.
  • Inspect connected components and export publication figures.

Output formats

Cytoscape session (.cys), network/table exports and figures

Scope and considerations

Designed for

  • Exploration of supplied graphs and linked attribute tables.

Not designed for

  • Raw MS peak picking or confirmation of metabolite identity.

Important requirements

  • An upstream network, stable node identifiers and matching metadata.
  • A compatible desktop installation and any required apps.

Considerations

  • Check node identifiers when joining quantitative tables.
  • Edge definitions and filtering come from upstream analysis; layout distances are not chemical evidence.
