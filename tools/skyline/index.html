Overview

Skyline supports chromatogram inspection, transition-based methods, calibration and quantitative reporting. Dedicated tutorials cover metabolomics and lipidomics applications.

What can this tool do?

Calibration-curve quantificationChromatogram building

Common uses

  • Review targeted small-molecule peak integration.
  • Quantify analytes using external calibration and internal standards.

Scientific fit

Primary function

Quantification and targeted analysis

Data compatibility

Inputs

Raw instrument data, Compound list or annotations

Outputs

Input formats

Vendor raw format

Output formats

CSV or TSV

Scope and considerations

Designed for

  • Review targeted small-molecule peak integration.

Not designed for

  • Unrestricted discovery of all unknown compounds in a raw file.

Important requirements

  • A compatible installation, assay targets and supported measurement files.

Considerations

  • Confirm transition specificity, calibration range and internal-standard behavior before reporting concentrations.
