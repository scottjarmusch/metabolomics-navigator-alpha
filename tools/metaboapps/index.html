Overview

MetaboApps is a GNPS2 collection of lightweight downstream applications built to make specialized post-processing analyses accessible without bespoke scripting. The current collection includes applications for post-network MassQL, multi-step MassQL, drug and food readouts, CMMC analysis, FBMN statistics, chemical proportionality, CorrOmics, conjugated-metabolome exploration, and reverse-metabolomics-style analyses. Individual apps remain separate scientific modules, while this Navigator entry represents the maintained collection as a discovery and launch layer.

What can this tool do?

Interactive dashboardProvenance tracking

Common uses

  • Launch modular downstream analyses from GNPS2/molecular-networking outputs without writing custom scripts.
  • Explore statistics, chemical pattern queries, drug/food annotations, microbial knowledge, and other specialized post-processing applications.
  • Provide a discoverable collection for rapidly evolving community analysis modules while keeping core GNPS2 workflows separate.
  • Apply an appropriate downstream app to a GNPS2 result and retain the underlying feature and sample identifiers.

Scope and considerations

Designed for

  • Post-processing and interpretation of GNPS2 and related metabolomics analysis outputs using modular web applications.

Not designed for

  • One universal workflow with identical input formats, outputs or validation across every app.

Important requirements

  • Inputs vary by app and can include GNPS2 task identifiers, feature/network tables, spectra, or metadata.

Considerations

  • MetaboApps is a collection rather than one analytical algorithm; users should cite and document the specific app(s) used.
  • Apps can evolve or be added more rapidly than peer-reviewed methodological publications.
  • Choose the app first, then check its input contract and cited method; record its name, parameters and upstream task identifier.
