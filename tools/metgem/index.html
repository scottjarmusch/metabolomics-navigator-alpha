Overview

MetGem loads tandem mass spectra and optional metadata, computes spectral similarities and offers molecular-network or projection views. It provides a local route for exploring processed LC-MS/MS spectra. Graph layouts and t-SNE projections are different representations and should not be interpreted as validated chemical structures.

What can this tool do?

Network visualization

Common uses

  • Build local molecular networks from processed MS/MS spectra.
  • Compare network views with spectral projections.

Scope and considerations

Designed for

  • Spectral-similarity calculation and interactive exploration.

Not designed for

  • Vendor raw-file preprocessing or confident identification from projection position.

Important requirements

  • Processed MGF or MSP tandem spectra and suitable precursor metadata.

Considerations

  • Record spectral filters, tolerances and similarity thresholds.
  • t-SNE emphasizes local relationships; global distances and layout changes can mislead.
