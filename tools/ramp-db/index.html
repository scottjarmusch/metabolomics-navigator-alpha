Overview

RaMP-DB integrates metabolite and gene/protein identifiers with pathway, reaction, chemical and ontology annotations. Researchers can query the resource through a browser, API or R package and perform downstream enrichment on MS-derived metabolite lists. Database coverage, mapping and the chosen background determine what can be interpreted.

What can this tool do?

Pathway enrichment

Common uses

  • Map metabolite identifiers across pathway resources.
  • Perform pathway enrichment with metabolites or combined gene/metabolite lists.
  • Retrieve pathway, reaction and ontology context programmatically.

Scope and considerations

Designed for

  • Biological interpretation and identifier harmonization after metabolite or gene-level results are available.

Not designed for

  • Raw mass-spectrometry preprocessing or primary metabolite identification.

Important requirements

  • Mapped metabolite identifiers with database prefixes, or supported gene/protein identifiers.
  • For local R use, the package dependencies and a cached RaMP database; use a recorded database version.

Considerations

  • Pathway results depend on identifier mapping, source-database coverage, background definition and the biological context of the study.
  • Inspect unmapped and multiply mapped identifiers; enrichment does not validate the original MS annotation.

Access and documentation

Primary access↗Source repository↗Documentation↗

The R package declares GPL-2 and provides local access through a downloaded SQLite database. Public web and API interfaces are also available. The software license does not replace the terms of contributing source databases; record both package and database versions.
