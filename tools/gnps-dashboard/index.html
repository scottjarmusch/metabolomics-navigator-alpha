Overview

GNPS Dashboard provides interactive browser-based exploration of mass-spectrometry files and public repository data. It can render chromatographic and spectral views, inspect individual scans, generate TIC/XIC-style traces, support targeted/SRM-style visualization, and link directly from GNPS analyses and public datasets. It also helps users identify and share spectra through Universal Spectrum Identifiers and connect raw-data inspection with downstream GNPS2 workflows.

What can this tool do?

Interactive dashboardChromatogram buildingProvenance tracking

Common uses

  • Interactively inspect raw/public LC-MS and other supported MS files in a browser.
  • Visualize chromatograms, extracted ion traces, spectra, and targeted transitions without installing local software.
  • Navigate from public repository files or GNPS2 analyses to individual scans and shareable spectrum identifiers.
  • Inspect chromatographic peaks and scan-level evidence underlying an annotation or unexpected sample signal.

Scope and considerations

Designed for

  • Rapid visual inspection and collaborative exploration of raw or public mass-spectrometry data.

Not designed for

  • Replacing a validated quantitative preprocessing pipeline or formal statistical analysis.

Important requirements

  • A supported public-file reference, repository dataset, or uploaded/accessible data source.

Considerations

  • Dashboard visualization complements rather than replaces comprehensive quantitative preprocessing and statistical workflows.
  • Available plots and data access depend on file format and repository availability.
  • Preserve a shareable view or file/scan identifier, and distinguish interactive visualization settings from analytical processing parameters.
