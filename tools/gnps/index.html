Overview

GNPS/GNPS2 is a web-based ecosystem for analysis, annotation, visualization, curation, and reuse of tandem mass-spectrometry data. GNPS2 organizes its current infrastructure around computational workflows, interactive visualization, mass-spectrometry knowledgebase curation, and large-scale data integration. The ecosystem includes molecular networking, library searching, MASST/FASST-based public-data search, domain-specific MASST services, MassQL, Pan-ReDU, GNPS Dashboard, CMMC resources, MetaboApps, and interoperable workflows with external processing software.

Also known as: Global Natural Products Social Molecular Networking, GNPS2

What can this tool do?

Interactive dashboardSpectral-library matchingMetadata-based contextualizationNetwork visualizationProvenance trackingRepository-scale spectral search

Common uses

  • Search experimental MS/MS spectra against community and reference spectral libraries.
  • Build classical, feature-based, and ion-identity molecular networks for untargeted MS/MS datasets.
  • Search public metabolomics repositories using MASST, FASST-based services, and domain-specific MASST resources.
  • Visualize raw data and analysis results, harmonize metadata, curate knowledge resources, and launch downstream GNPS2/MetaboApps analyses.
  • Connect feature abundances to spectral similarity networks and inspect library annotations in experimental context.

Scope and considerations

Designed for

  • MS/MS-centered annotation, molecular networking, public-data search, visualization, and community sharing of metabolomics and natural-products data.
  • Web-based workflows that integrate processed feature tables, spectra, sample metadata, and public mass-spectrometry datasets.

Not designed for

  • Establishing a confirmed compound identity solely from a network edge or spectral-library score.

Important requirements

  • Inputs depend on the selected workflow; molecular-networking workflows generally require centroided MS/MS data, while FBMN also requires a feature table and representative MS/MS spectra.
  • Appropriate metadata, feature-processing parameters, and workflow settings should be recorded for reproducible analysis.

Considerations

  • GNPS is an ecosystem rather than a single algorithm; publications should report the specific workflow, parameters, and task URL or identifier used.
  • GNPS2 is actively evolving, and workflow interfaces or recommended settings can change; consult the current documentation when reproducing older analyses.
  • Not every GNPS2 web utility is represented as a separate Navigator entry; dedicated entries are reserved for stable, reusable resources with distinct scientific functions.
  • Preserve the task identifier, input feature IDs, metadata and library information so annotations can be traced to the original data.
