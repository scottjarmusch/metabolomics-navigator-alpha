Overview

LC-MS2Struct uses a structured support vector machine to combine relative elution order with spectral candidate scores across a set of features. It returns candidate rankings after preprocessing and candidate generation; it does not generate an end-to-end workflow from raw files.

Also known as: LC-MS²Struct

What can this tool do?

Structure elucidation

Common uses

  • Re-rank ambiguous candidates using the retention order shared across an LC-MS/MS run.

Scope and considerations

Designed for

  • Jointly rank molecular candidates using LC retention order and precomputed MS/MS scores.

Not designed for

  • Replacing experimental confirmation of compound identity.
  • Raw-data feature detection or chromatographic alignment.

Important requirements

  • Linux and the documented Conda environment; the README does not support other operating systems.
  • The separate msmsrt_scorer dependency, suitable model/training data, per-feature candidate structures and MS/MS scores, and measured retention times.
  • Prepare inputs using the linked manuscript experiment scripts; this is a research Python implementation.

Considerations

  • The published evaluation uses reversed-phase LC data; evaluate transfer to your chromatographic conditions.
  • Candidates absent from the input sets cannot be recovered by re-ranking.
  • Joint scores depend on candidate and model quality; a high rank does not establish stereochemistry.
