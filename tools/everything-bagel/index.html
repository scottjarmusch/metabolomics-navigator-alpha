Overview

Everything Bagel is a feature-finding resource for untargeted LC-MS analysis. Its 2026 preprint describes feature detection, retention-time alignment and gap filling. The GNPS2-hosted workflow combines feature finding with FBMN, making this an upstream processing route into subsequent network interpretation.

Also known as: Everything Bagel Feature Finder, Everything Bagel Workflow

What can this tool do?

Peak or feature detectionRetention-time alignmentGap filling

Common uses

  • Generate aligned quantitative features from LC-MS data.
  • Connect raw-data processing with GNPS2 feature-based molecular networking.

Scope and considerations

Designed for

  • Untargeted LC-MS feature finding and a raw-data-to-FBMN workflow.

Not designed for

  • A downstream statistical-analysis replacement or proof of compound identity.

Important requirements

  • A GNPS2 account and compatible LC-MS(/MS) data; check the workflow form for file and parameter requirements.

Considerations

  • The dedicated publication is a preprint, not a peer-reviewed validation.
  • Reported speed and benchmark performance are author claims and were not independently reproduced here.
  • It is an upstream workflow, not solely an analysis of a previously generated network.
