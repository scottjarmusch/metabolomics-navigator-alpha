Overview

MS2DeepScore uses a Siamese neural network to predict fingerprint-based similarity and generate spectral embeddings. Model versions differ in supported ionization modes.

What can this tool do?

Spectral-library matching

Common uses

  • Prioritize potentially related molecules from MS/MS spectra.
  • Explore spectral collections through learned embeddings.

Scope and considerations

Designed for

  • Prioritize potentially related molecules from MS/MS spectra.

Not designed for

  • Interpreting predicted similarity as an identification probability.

Important requirements

  • Python, cleaned spectra and a compatible model checkpoint.

Considerations

  • Use a model appropriate to the ion mode and chemical domain; report model version and preprocessing.
