Overview

PNNL PreProcessor is a desktop preprocessing utility developed for ion-mobility mass spectrometry. It supports Agilent MassHunter and UIMF data from drift-tube and SLIM IM-MS platforms and provides operations including data compression/interpolation, ion-mobility demultiplexing, multidimensional smoothing, intensity-threshold and spike filtering, saturation repair, metadata export, and selected conversions that make IM information usable in downstream LC-MS-oriented workflows.

What can this tool do?

Spectral deconvolution

Common uses

  • Improve signal quality before downstream LC-IM-MS data processing.
  • Demultiplex and smooth ion-mobility data and remove low-intensity or spike noise.
  • Convert selected IM-MS data representations for use with downstream workflows.

Scope and considerations

Designed for

  • Preprocessing Agilent drift-tube and SLIM ion-mobility MS data before downstream omics analysis.

Not designed for

  • General-purpose metabolite annotation or statistical analysis.

Important requirements

  • Compatible Agilent MassHunter .d or UIMF input data and a supported desktop environment.

Considerations

  • Saturation repair can produce incorrect results for highly convoluted elution or mobility profiles; output logs should be inspected.
