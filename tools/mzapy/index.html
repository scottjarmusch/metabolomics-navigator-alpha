Overview

mzapy is a Python package for accessing and manipulating multidimensional mass-spectrometry data. It was developed around MZA and supports data extraction, plotting, selected calibration tasks, signal processing, peak finding, and programmatic access to dimensions such as retention time, ion mobility, mass-to-charge ratio, and intensity. It is particularly useful for scripting LC-IM-MS workflows and for prototyping downstream analyses on data converted to MZA.

What can this tool do?

Chromatogram buildingPeak or feature detectionMS/MS processing

Common uses

  • Extract retention-time, ion-mobility and m/z slices from multidimensional MS datasets.
  • Build scripted LC-IM-MS analysis and visualization workflows in Python.
  • Work programmatically with MZA files generated from vendor or mzML data.

Scope and considerations

Designed for

  • Programmatic access and lightweight analysis of multidimensional MS data, especially ion-mobility datasets.

Not designed for

  • Complete untargeted feature processing or metabolite identification by itself.

Important requirements

  • A compatible Python environment and supported input data such as MZA.

Considerations

  • Ion-mobility workflows require appropriate calibration and interpretation of the mobility dimension; extraction utilities do not by themselves establish metabolite identity.
