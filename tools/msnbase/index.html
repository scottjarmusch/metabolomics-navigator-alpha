Overview

MSnbase supplies data classes and functions spanning spectra and quantitative measurements. It is infrastructure used in analytical workflows, including metabolomics.

What can this tool do?

MS/MS processing

Common uses

  • Inspect and manipulate spectra programmatically.
  • Maintain compatibility with R workflows built around MSnbase objects.

Scientific fit

Primary function

Spectral processing and comparison

Data compatibility

Inputs

Mass spectra, Feature or peak table

Outputs

Mass spectra, Feature or peak table

Input formats

Other, Spectra and MSnbase quantitative objects

Output formats

Other, MSnbase spectral and quantitative objects

Scope and considerations

Designed for

  • Inspect and manipulate spectra programmatically.

Not designed for

  • A ready-made end-to-end metabolomics pipeline without additional methods.

Important requirements

  • R/Bioconductor and data compatible with the package import functions.

Considerations

  • Check object compatibility when combining older MSnbase workflows with newer Spectra-based packages.
