Evidence and review

This software addresses traditional shortcomings in metabolomics data analysis by using an end-to-end workflow based on the region-of-interest (ROI) approach modeled after NMR software. In MS-MINT, ROIs are defined as windows of retention time and m/z that are extracted from MS1 spectra. Each metabolite is therefore defined by a specific ROI, which can then be extracted from each spectrum and visualized or analyzed by data processing algorithms.
