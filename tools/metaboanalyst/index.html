Overview

MetaboAnalyst combines web modules for statistical analysis, functional interpretation and integration of metabolomics results. Researchers can start with abundance tables and sample metadata, annotated metabolite lists, or supported LC-MS spectra. MetaboAnalyst 6.0 includes MS/MS annotation, analysis with covariates, dose-response analysis and genetic association-based causal analysis. MetaboAnalystR supports scripted workflows. Inputs and outputs depend on the module, so users should identify the analysis performed rather than report only the platform name.

Common uses

  • Perform exploratory and inferential statistics on metabolomics data tables.
  • Generate visualizations and pathway-level interpretations.
  • Integrate metabolomics with transcriptomics or other omics results.
  • Save result tables and the analysis settings so statistical and pathway results can be reconstructed.

Scope and considerations

Designed for

  • Exploratory and inferential analysis of metabolomics abundance tables with a defined study design.
  • Pathway and metabolite-set analysis using annotated compounds or supported untargeted peak lists.

Not designed for

  • Treating a predictive model or pathway association as experimentally established biological causation.

Important requirements

  • Prepare sample labels and covariates consistently with the selected statistical module.
  • For pathway analysis, inspect identifier mapping and choose the relevant organism and background; raw-data modules have separate input requirements.

Considerations

  • Report missing-value handling, normalization, transformation, scaling and multiple-testing choices.
  • Evaluate supervised models with appropriate validation; a separated score plot alone is insufficient evidence of predictive performance.
  • The public web service and optional commercial services have different limits and deployment options.
  • Check the number of compounds that map to the selected pathway resource and report the background used for enrichment.
