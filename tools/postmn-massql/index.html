Overview

PostMN MassQL searches the processed spectra from a completed GNPS2 networking job. Researchers can select, edit or write fragmentation-pattern queries and inspect which spectra satisfy them, alongside available library annotations.

What can this tool do?

MS/MS processingProvenance tracking

Common uses

  • Screen networking results for diagnostic fragments or neutral losses.
  • Export spectra satisfying selected query conditions.

Output formats

MGF, CSV or TSV

Scope and considerations

Designed for

  • Chemical-pattern searching after classical or feature-based molecular networking.

Not designed for

  • Raw-file preprocessing or conclusive identification from a query hit alone.

Important requirements

  • A completed, public GNPS2 CMN or FBMN task and a valid MassQL query.

Considerations

  • A query hit supports a fragmentation hypothesis; it does not validate a full structure.
  • The app searches processed spectra, so upstream processing affects the available evidence.
  • Retain the executed query text and upstream task identifier with exported results.
