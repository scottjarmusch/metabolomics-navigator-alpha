Overview

MatrixQCvis is a Bioconductor/Shiny interface for inspecting quantitative matrices. It visualizes distributions, sample relationships, outliers and batch structure, using SummarizedExperiment as its input container.

What can this tool do?

Interactive dashboard

Common uses

  • Inspect processed MS-metabolomics matrices before interpretation.

Scientific fit

Primary function

Quality control and filtering

Data compatibility

Inputs

Feature or peak table, Sample metadata

Outputs

Human-readable report

Input formats

SummarizedExperiment object supplied directly or as an RDS file

Output formats

Interactive per-sample and per-feature quality visualizations

Scope and considerations

Designed for

  • Explore sample and feature quality in metabolomics matrices through interactive visualizations.

Not designed for

  • Confirming compound identity or replacing study design and scientific review.

Important requirements

  • A feature-by-sample matrix and metadata prepared as a SummarizedExperiment object.

Considerations

  • Visual separation alone cannot determine whether a batch difference is technical or biological.
  • Use the compatible Bioconductor release rather than assuming the development branch is production-ready.
