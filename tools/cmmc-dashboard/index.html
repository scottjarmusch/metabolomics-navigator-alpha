Overview

CMMC Dashboard brings together CMMC enrichment, FBMN abundances and sample metadata. It provides group comparisons, overlap views, molecular-network displays and microbeMASST links for exploring microbial metabolite hypotheses.

What can this tool do?

Metadata-based contextualizationInteractive dashboardNetwork visualization

Common uses

  • Inspect microbial-metabolite annotations alongside sample abundances.
  • Explore overlap between source categories and potential microbial contexts.

Scientific fit

Primary function

Visualization and reporting

Data compatibility

Inputs

Feature or peak table, Sample metadata

Outputs

Human-readable report, Statistical results

Input formats

CSV or TSV, Completed CMMC enrichment and FBMN task IDs, Sample metadata can also use Excel or TXT

Output formats

Interactive box plots, UpSet plots, networks and microbial search views

Scope and considerations

Designed for

  • Downstream exploration after CMMC enrichment and FBMN processing.

Not designed for

  • Replacing CMMC enrichment or establishing the producer of a metabolite in a mixed sample.

Important requirements

  • Completed CMMC enrichment and FBMN task identifiers, plus sample metadata.
  • Metadata sample names must exactly match the FBMN quantification table.

Considerations

  • Interpret source annotations and microbeMASST matches as supporting context rather than proof of origin.
  • Quantitative comparisons depend on upstream processing and appropriate sample grouping.
