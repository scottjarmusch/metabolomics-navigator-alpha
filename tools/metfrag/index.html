Overview

MetFrag retrieves structures using precursor information and scores their in silico fragments against measured peaks. Optional evidence scores can supplement fragmentation. Use it after extracting spectra when you need a transparent, configurable candidate-ranking workflow.

What can this tool do?

Structure-database searchingIn-silico spectrum prediction

Common uses

  • Prioritize structures for an unknown MS/MS spectrum.
  • Repeat annotation with an explicitly recorded candidate database and scoring configuration.

Output formats

SDF, CSV or TSV

Scope and considerations

Designed for

  • Database-constrained structure annotation from prepared spectra.

Not designed for

  • Detecting or aligning chromatographic features from raw files.

Important requirements

  • Supply precursor mass or formula, ion/adduct settings, a peak list and mass tolerances; Java is needed for local command-line use.

Considerations

  • A correct structure must be represented in the candidate set. A high rank is supporting evidence, not confirmation with an authentic standard.
