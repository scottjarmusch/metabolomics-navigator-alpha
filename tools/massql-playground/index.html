Overview

MassQL Playground parses queries, explains their structure and runs them against local data in the browser. It provides a lightweight way to develop a spectral query before using the same language in larger analyses.

What can this tool do?

MS/MS processing

Common uses

  • Develop and inspect fragmentation-pattern queries.
  • Search a local spectral file and export matching rows.

Scope and considerations

Designed for

  • Interactive MassQL query development and local spectral searching.

Not designed for

  • Raw feature detection or definitive molecular identification from a query match.

Important requirements

  • A modern browser and a supported local spectral file for execution.

Considerations

  • The app reads whole files into browser memory; large files may exceed available resources.
  • Displayed rows are capped even when the reported match count is larger.
  • Retain the query and input-file identity to make results reproducible.
