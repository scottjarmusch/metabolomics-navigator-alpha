Overview

dbnorm provides R functions for batch adjustment and diagnostic visualization. It includes empirical-Bayes and two-stage approaches and compares corrected data structure. Model selection does not establish that biological differences were preserved.

What can this tool do?

Batch-effect correction

Common uses

  • Inspect and compare batch-adjustment results.

Corrected CSV matrices and diagnostic PDF plots

Scope and considerations

Designed for

  • Compare statistical batch-correction models and inspect technical variation in metabolomics matrices.

Not designed for

  • Confirming compound identity or replacing study design and scientific review.

Important requirements

  • Processed metabolomics data, batch labels and compatible R dependencies.
  • CSV matrix with samples in rows, features in columns and batch labels; follow documented normalization/log2 preparation

Considerations

  • Confounding between batch and biological groups requires assessment before correction.
  • The documented setup includes archived R dependencies.
