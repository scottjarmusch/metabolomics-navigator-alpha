Overview

M²aia extends the Medical Imaging Interaction Toolkit with MSI signal processing and image interaction. Researchers can inspect ion images and reconstruct or register spatial datasets. The related pyM²aia project exposes programmatic functionality separately.

Also known as: M2aia

What can this tool do?

Spectral data reading and writingPeak or feature detectionContainer support

Common uses

  • Interactively inspect and process MSI spectra and ion images.
  • Register multimodal images and reconstruct three-dimensional MSI datasets.

Scope and considerations

Designed for

  • Interactive spatial-data exploration and MSI image processing.

Not designed for

  • Definitive metabolite identification from image colocalization alone.

Important requirements

  • A compatible Windows or Linux installation, or the documented container environment.
  • The project specifies elastix for image-registration utilities.

Considerations

  • Inspect registration quality and processing parameters before interpreting spatial overlap.
  • Memory and storage requirements depend on image size and processing choices.
  • Python workflows use the companion pyM²aia interface; desktop and Python capabilities are not assumed identical.
