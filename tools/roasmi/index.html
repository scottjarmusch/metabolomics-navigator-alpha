Overview

ROASMI learns molecular representations and pairwise elution preferences using a neural ranking model. Its supplied scripts predict retention scores, optionally retrain models, and integrate retention evidence with MS/MS candidate scores.

What can this tool do?

Structure elucidation

Common uses

  • Add chromatographic evidence to molecular candidate ranking.
  • Retrain a retention-order model with a suitable reference set.

Scope and considerations

Designed for

  • Predict relative LC retention behavior and combine it with MS/MS scores to rank candidate structures.

Not designed for

  • Replacing experimental confirmation of compound identity.
  • Raw-data feature detection or chromatographic alignment.

Important requirements

  • Python/Conda and the documented dependencies, model files and candidate structures.
  • Prepare input CSV files using the repository prediction and identification examples. Identification requires the expected retention and candidate-score information.
  • Select reference data and models compatible with the chromatographic mode and buffer pH.

Considerations

  • The supplied initial models target reversed-phase LC around pH 2.7; they are not universal retention models.
  • The repository supplies retraining examples, including HILIC. That does not establish general applicability of the initial RPLC models to HILIC.
  • CPU execution is documented; GPU acceleration is recommended for faster retraining, not required for all use.
  • Retention scores describe relative order, not necessarily calibrated absolute retention times.
