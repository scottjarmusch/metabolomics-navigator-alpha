MetLinkR

MetLinkR is an R package used for cross-linking of metabolite identifiers across disparate data sets. It uses RefMet and RaMP-DB links to recognize metabolites referred to by different names or database identifiers. MetLinkR can be used as an R package or accessed through the RaMP-DB web interface.

Overview

MetLinkR is an R package used for cross-linking of metabolite identifiers across disparate data sets. It uses RefMet and RaMP-DB links to recognize metabolites referred to by different names or database identifiers. MetLinkR can be used as an R package or accessed through the RaMP-DB web interface.
