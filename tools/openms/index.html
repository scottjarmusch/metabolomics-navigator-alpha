Overview

OpenMS is a modular framework for building mass-spectrometry workflows. Researchers can combine TOPP command-line tools, inspect data with TOPPView, assemble graphical workflows, or use the C++ library and pyOpenMS in their own software. Metabolomics workflows connect feature detection, retention-time alignment, feature grouping and annotation; open formats allow intermediate results to move between tools. The selected workflow determines the supported acquisition mode and outputs.

What can this tool do?

Peak or feature detectionRetention-time alignmentGap fillingProvenance tracking

Common uses

  • Assemble reproducible command-line or Python workflows for LC-MS data processing.
  • Convert, inspect, detect, align, quantify, and annotate mass spectrometry features.
  • Inspect featureXML or consensusXML intermediates and export a table for downstream interpretation.

Scope and considerations

Designed for

  • Reproducible LC-MS processing with explicit intermediate files and reusable workflow parameters.
  • Custom pipelines that combine mass-spectrometry algorithms with Python or C++ analysis.

Not designed for

  • A single automatic analysis with universally appropriate parameters for every metabolomics experiment.

Important requirements

  • Install OpenMS or pyOpenMS and the dependencies of the selected workflow; graphical workflow systems are separate installations.
  • Convert proprietary data to an accepted open format when the selected tool cannot read the original file.

Considerations

  • Feature detection, alignment and grouping need parameters appropriate to chromatography, resolution and sample complexity.
  • Keep workflow files, parameter files, software versions and reference databases alongside the exported results.
  • Select the metabolomics-specific workflow and inspect its intermediate results rather than applying proteomics defaults unchanged.
