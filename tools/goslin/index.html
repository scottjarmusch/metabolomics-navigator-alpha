Overview

Goslin defines grammars for lipid shorthand notation, with implementations in several programming languages and a web/API project. Goslin 2.0 incorporates updated structural levels. This canonical entry covers the grammar ecosystem rather than treating each implementation as a separate analytical tool.

What can this tool do?

Identifier harmonization

Common uses

  • Validate lipid shorthand before integrating result tables.
  • Normalize supported lipid names within scripted analysis pipelines.

Scope and considerations

Designed for

  • Grammar-based parsing of supported lipid nomenclatures.

Not designed for

  • Identification from spectra or confirmation of double-bond positions.

Important requirements

  • Lipid name strings and a suitable Goslin implementation.

Considerations

  • Record the parser version and inspect rejected names.
  • Syntactic validity does not establish experimental identification confidence.
