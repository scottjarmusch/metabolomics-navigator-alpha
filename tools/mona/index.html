Overview

MassBank of North America brings spectra, structures and metadata together in a searchable resource. Web queries and documented REST queries help retrieve records by metadata, while downloadable collections support use in other tools.

Also known as: MassBank of North America

What can this tool do?

Metadata-based contextualizationProvenance tracking

Common uses

  • Retrieve spectra using compound identifiers or acquisition metadata.
  • Download a library subset appropriate for an annotation tool.

Scope and considerations

Designed for

  • Reference-library discovery and metadata-based retrieval.

Not designed for

  • A repository for a complete study and its raw sample files.

Important requirements

  • Select the relevant spectral collection and export format; use pagination for programmatic queries.

Considerations

  • Inspect record origin and evidence type. Overlap between source collections means aggregated records are not necessarily independent reference measurements.

Access and documentation

Primary access↗Documentation↗

Public browsing and downloads are available. Check the originating collection and applicable reuse terms rather than assuming a single license covers all aggregated records.
