Overview

TinyMass accepts a peak list and an optional precursor m/z through a web form. The GNPS2 documentation describes it as a way to share a spectrum and obtain a Universal Spectrum Identifier for use by other tools.

What can this tool do?

Provenance tracking

Common uses

  • Share individual spectra for discussion or downstream visualization.
  • Reference a spectrum in compatible GNPS2 tools.

Scope and considerations

Designed for

  • Lightweight sharing of individual mass spectra.

Not designed for

  • Private data storage
  • full experimental-data deposition or molecular identification.

Important requirements

  • Internet access and a peak list suitable for the submission form.

Considerations

  • Treat submitted spectra as shared data. The GNPS2 library search interface states that peak lists deposited through its TinyMass integration are retained indefinitely.
  • Keep original files and acquisition metadata; a shared spectrum alone does not capture experimental provenance.
  • Confirm identifier retrieval and downstream compatibility before relying on it in a published workflow.
