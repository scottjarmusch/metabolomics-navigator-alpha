Overview

The USI Playground provides separate forms for dataset identifiers, feature-based molecular networking tasks and MassIVE paths. These helpers support assembling references for downstream spectrum access; they do not establish metabolite identities.

What can this tool do?

Interactive dashboard

Common uses

  • Prepare references for retrieving spectra in downstream tools.
  • Link GNPS2 feature-based molecular networking results to spectrum identifiers.

Scope and considerations

Designed for

  • Identifier preparation for public MS data and GNPS2 analysis results.

Not designed for

  • Raw-data processing, annotation or long-term data deposition.

Important requirements

  • Valid accessible dataset, task or file-path references for the selected form.

Considerations

  • A reference depends on the availability and structure of the underlying data.
  • Correct identifier formatting does not establish spectrum quality or molecular identity.
  • The FBMN form displayed a Streamlit deprecation warning during review; verify downloaded results before downstream use.
