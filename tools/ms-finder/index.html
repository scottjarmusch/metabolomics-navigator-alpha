Overview

MS-FINDER combines formula prediction, fragment interpretation and structure ranking. Its graphical and console interfaces support spectral-library searching and in silico prediction. It operates on prepared spectra, making it a companion to upstream processing tools.

Also known as: MSFINDER

What can this tool do?

Molecular-formula predictionStructure elucidationSpectral-library matching

Common uses

  • Rank candidate formulas and structures for unknown spectra.
  • Search EI-MS or MS/MS libraries through the GUI or a batch console job.

Scientific fit

Primary function

Metabolite annotation and identification

Data compatibility

Inputs

Mass spectra, Spectral library

Outputs

Compound list or annotations, Human-readable report

Input formats

MSP, MS-FINDER MAT (spectral text format)

Output formats

MS-FINDER ASCII result files

Scope and considerations

Designed for

  • Interpretation of prepared small-molecule mass spectra.

Not designed for

  • Replacing raw-data peak detection and alignment.

Important requirements

  • Prepare MSP or MS-FINDER MAT files and configure precursor and mass-error settings. Check distribution requirements before installation.

Considerations

  • Fragmentation rules and library coverage constrain the result; review ambiguous candidates and retain the parameter file.
