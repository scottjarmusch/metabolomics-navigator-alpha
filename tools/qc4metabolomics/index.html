Overview

QC4Metabolomics provides a locally deployed QC system with background processing, a MariaDB database and a Shiny interface. Its MetabolomiQCsR component supplies QC functions. Optional conversion services prepare mzML inputs.

Also known as: MetabolomiQCsR

Scope and considerations

Designed for

  • Monitor LC-MS data quality with a configurable processing service, database and dashboard.

Not designed for

  • Confirming compound identity or replacing study design and scientific review.

Important requirements

  • Docker/Compose, configured data volumes, database and background workers.

Considerations

  • This is infrastructure to deploy and configure, not simply a public upload website.
  • File naming and metadata parsing must match the local acquisition setup.
