Overview

microbiomeMASST extends domain-specific repository searching from curated monocultures to a harmonized network of microbiome metabolomics datasets and metadata. It is designed to reveal where molecules occur across host-associated and microbial study contexts and to make large public microbiome metabolomics collections searchable through spectrum-to-metadata relationships. The scientific description is currently available as a 2026 preprint.

What can this tool do?

Repository-scale spectral searchMetadata-based contextualizationNetwork visualization

Common uses

  • Map query spectra across harmonized microbiome metabolomics datasets and metadata contexts.
  • Explore host, sample, microbial, and experimental contexts associated with matching spectra.
  • Generate hypotheses about metabolite distributions across microbiome studies using public data.
  • Follow spectrum-to-metadata associations to source studies for focused reanalysis.

Scope and considerations

Designed for

  • Repository-scale contextualization of metabolites across microbiome metabolomics metadata networks.

Not designed for

  • Inferring causation or identifying a microbial producer from cross-study metadata associations alone.

Important requirements

  • Query MS/MS information and public-data metadata indexed by the current resource.

Considerations

  • The primary scientific description is a preprint and the underlying metadata network is actively evolving.
  • Associations from public-data co-occurrence are hypothesis-generating and can reflect sampling, deposition, or study-design biases.
  • Check study membership and available controls because repeated samples and heterogeneous studies are not independent biological replications.
