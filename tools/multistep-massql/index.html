Overview

Multi-step MassQL applies successive fragmentation rules to spectra from a GNPS2 networking task. The documented app is configured for bile-acid classification, with a classification tree and result tables for inspecting individual features.

What can this tool do?

MS/MS processingCompound-class prediction

Common uses

  • Apply consistent bile-acid query logic across processed datasets.
  • Inspect alternative classifications for a feature.

Scope and considerations

Designed for

  • Bile-acid-focused analysis of completed molecular-networking results.

Not designed for

  • A general-purpose sequential-query interface for arbitrary metabolite classes.
  • Unqualified confirmation of stereochemistry from every matching spectrum.

Important requirements

  • A completed, public GNPS2 CMN or FBMN task containing relevant MS/MS spectra.

Considerations

  • Current documentation limits the app to bile acids; broader classes are described as future work.
  • Mixed spectra can satisfy multiple classifications. Inspect the evidence behind each assignment.
  • The app uses preconfigured queries; document the application version and upstream task when reporting results.
