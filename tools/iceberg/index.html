Overview

ICEBERG predicts tandem mass spectra from candidate molecular structures using a learned fragment generator and an intensity predictor. Predicted spectra can be compared with an experimental spectrum to rank supplied candidates. The ms-pred repository also contains separate models; this entry covers ICEBERG, not every method in that repository.

What can this tool do?

Structure elucidation

Common uses

  • Predict MS/MS spectra for candidate structures.
  • Rank a defined candidate set by comparison with an experimental spectrum.

Scope and considerations

Designed for

  • Structure-to-spectrum prediction and candidate ranking for small molecules.

Not designed for

  • Raw chromatographic feature extraction or guaranteed de novo identification from a spectrum.

Important requirements

  • Use matching model weights, molecular-structure inputs and model-specific acquisition metadata. Follow the prediction example for the chosen ICEBERG version.

Considerations

  • Candidate ranking is limited by the supplied candidate set and model applicability.
  • The repository distinguishes ICEBERG 1.0, 2.0 and 2.1. Record the model and weights used.
  • Training hardware requirements must not be presented as the minimum requirement for pretrained inference.
  • Software execution and prediction performance were not tested during this editorial preparation.
