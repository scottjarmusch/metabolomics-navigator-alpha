Overview

`ili maps quantitative molecular or omics features onto 2D images or 3D surface models. It accepts a spatial mapping table plus a background image or 3D model and supports reusable visualization snapshots and shareable links.

Also known as: ili

What can this tool do?

Interactive dashboard

Common uses

  • Visualize molecular features across 2D biological surfaces.
  • Map metabolomics features onto 3D models.

Scope and considerations

Designed for

  • Interactive molecular cartography when feature intensities can be associated with spatial coordinates.

Not designed for

  • Raw MS preprocessing, statistical inference or identification from a spatial map alone.

Important requirements

  • Feature intensities matched to sample coordinates and a corresponding background image or model.

Considerations

  • Upstream normalization, annotation and statistical validation occur outside this visualization layer.
  • Spatial patterns depend on sampling density, coordinate accuracy and display settings.
