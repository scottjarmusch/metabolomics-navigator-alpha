Overview

FASST provides indexed tandem mass-spectral searching used by GNPS2 repository-search services. Its documented API supports querying indexed spectra and retrieving matches. Index coverage and service versions should be reported with any analysis.

Also known as: Fast Search Tool, FASST Records, FASSTrecords

What can this tool do?

Repository-scale spectral searchSpectral-library matching

Common uses

  • Search indexed public MS/MS collections in seconds rather than scanning repositories serially.
  • Provide the fast-search backend used by MASST and domain-specific MASST applications.
  • Support programmatic repository-scale spectral search through GNPS2 services.
  • Retrieve indexed spectral matches through the web interface or documented API for downstream metadata analysis.

Scope and considerations

Designed for

  • High-throughput exact/analog tandem mass-spectral searching across very large indexed collections.

Not designed for

  • Finding compounds that are absent from the selected spectral index, or proving absence from a sample.

Important requirements

  • A centroided query MS/MS spectrum or compatible query identifier and appropriate similarity/tolerance settings.

Considerations

  • FASST is infrastructure as well as a user-facing search service; many researchers encounter it indirectly through MASST-derived applications.
  • The content and versions of public indexes change over time.
  • Report the selected index, search date, precursor and fragment tolerances, similarity threshold and whether analog mode was enabled.
