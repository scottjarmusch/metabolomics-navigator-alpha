Overview

CorrOmics links metabolite abundances with microbial or other omics measurements using sample-mapping metadata. It provides correlation-network exploration and downloadable edges; inferred associations do not establish biological causation. Hosted and local execution routes are documented.

What can this tool do?

Interactive dashboard

Common uses

  • Explore metabolite-microbe abundance associations.
  • Export cross-omics association networks for inspection in Cytoscape.

Scope and considerations

Designed for

  • Exploratory association analysis of matched metabolomics and other omics samples.

Not designed for

  • Inferring causation, confirming metabolite identity or preprocessing raw MS files.

Important requirements

  • Paired abundance tables and metadata with filename and ATTRIBUTE_Corromics_filename sample mappings.
  • Local Python/Streamlit dependencies when running outside the hosted service.

Considerations

  • The documentation limits hosted analyses to one million correlations and recommends local execution above that.
  • Compositional effects, confounders, missing values and repeated measures require study-specific assessment.
  • Exploratory methods differ in interpretation and significance support; do not treat every association score as a corrected hypothesis test.
