Overview

MS2Query searches reference MS/MS spectra for both exact-match candidates and structurally related analogues. It combines Spec2Vec, MS2DeepScore and precursor information to rank library candidates, with a Python implementation and a hosted GNPS2 workflow.

What can this tool do?

Spectral-library matching

Common uses

  • Find plausible structural relatives when an exact library match is unavailable.
  • Prioritize spectra for closer structural investigation.

Scope and considerations

Designed for

  • Library searching of small-molecule MS/MS spectra, including analogue retrieval.

Not designed for

  • De novo structure generation or conclusive identification of an unknown molecule.
  • Chromatographic feature detection, alignment or quantification.

Important requirements

  • MS/MS spectra with precursor information and the correct ionization mode.
  • Compatible reference-library and model files; hosted jobs require uploaded spectra and a GNPS2 account.

Considerations

  • An analogue is a related reference molecule, not necessarily the measured compound.
  • Filter results by model score and inspect precursor differences; class labels describe the proposed library molecule.
  • Results depend on reference-library coverage and model compatibility. Record the library, model and software versions.

The current GNPS2 documentation asks industry users to contact the maintainers or UC Riverside Technology Transfer regarding organizational access. Workflow submission requires a GNPS2 account.
