Overview

Feature-Based Molecular Networking bridges upstream LC-MS/MS feature-processing tools with GNPS molecular networking. A quantitative feature table and representative MS/MS spectra are exported from software such as MZmine, MS-DIAL, XCMS, or OpenMS and used to build molecular networks in which each node corresponds to an aligned chromatographic feature.

What can this tool do?

Spectral-library matchingNetwork visualization

Common uses

  • Build molecular networks that retain chromatographic feature abundance across samples.
  • Layer metadata and quantitative information onto MS/MS molecular families.

Scope and considerations

Designed for

  • Untargeted LC-MS/MS studies where chromatographic feature detection and quantitative feature tables are important for molecular-network interpretation.
  • Resolving isomeric or chromatographically separated features that would otherwise be combined in purely spectrum-centric networking.

Not designed for

  • Definitive structure identification from spectral similarity alone.
  • Replacing experimental quality control or validating biological causation.

Important requirements

  • An aligned feature quantification table and representative MS/MS spectra exported from a compatible preprocessing workflow.
  • Matching feature identifiers between the quantification table and spectral summary; sample metadata is optional.

Considerations

  • The quality of the molecular network depends on upstream feature detection, alignment, MS/MS assignment, and preprocessing choices.
  • FBMN does not remove the need for independent structural validation; library matches and network propagation represent different levels of annotation evidence.
  • Raw mzML files are optional supporting inputs in the documented GNPS2 workflow; they do not replace the required processed feature table and spectral summary.

Access and documentation

Primary access↗Documentation↗

GNPS2 is openly available to the academic community. The current GNPS2 documentation asks industry users to contact the maintainers or UC Riverside Technology Transfer regarding organizational access. Workflow submission requires a GNPS2 account.
