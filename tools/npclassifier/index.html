Overview

NPClassifier assigns natural-product pathway, superclass and class labels from a supplied chemical structure. Within MS metabolomics it can organize already annotated compounds or candidate structures. It does not infer a structure directly from a mass spectrum.

What can this tool do?

Compound-class prediction

Common uses

  • Group candidate or annotated metabolites by natural-product chemical class.
  • Add structure-derived class labels to downstream metabolomics summaries.

Scope and considerations

Designed for

  • Biosynthetically informed classification of supplied natural-product structures.

Not designed for

  • Annotating an unknown MS/MS spectrum without a candidate structure.
  • Proving that a predicted class establishes biological origin or a biosynthetic route.

Important requirements

  • A valid molecular structure supplied as SMILES.
  • For local hosting, the model files and deployment dependencies described in the repository.

Considerations

  • Classification depends on the supplied structure; an incorrect structural annotation carries through to its class labels.
  • The natural-product ontology has its own class definitions and coverage; preserve that context when comparing classifications.

Access and documentation

Primary access↗Documentation↗

The hosted classifier is publicly accessible. The repository specifies MIT for software and CC0 for its data, models and ontology. Local deployment is documented; the repository also states that queried structures are logged by the hosted service.
