Overview

MS2LDA represents recurring fragmentation patterns as Mass2Motifs, which can support substructure interpretation across a dataset. The project now provides MS2LDA 2.0 and an updated visualization interface.

What can this tool do?

Substructure prediction

Common uses

  • Discover shared fragmentation motifs.
  • Explore motif occurrences across molecular families.

Scientific fit

Primary function

Spectral processing and comparison

Data compatibility

Inputs

Mass spectra

Outputs

Human-readable report, Statistical results

Input formats

Other, MS/MS peak lists

Output formats

Other, Mass2Motifs, associations and visualizations

Scope and considerations

Designed for

  • Discover shared fragmentation motifs.

Not designed for

  • Treating every motif as a uniquely established substructure.

Important requirements

  • Processed MS/MS spectra and a workflow compatible with the current MS2LDA implementation.

Considerations

  • Motif interpretation depends on spectral coverage and annotation evidence; the official site flags retirement of its legacy interface.
