Overview

The bridge packages an existing GNPS2 network with node and edge tables and sample-group styling for desktop inspection. It does not calculate spectral similarity or build the original network.

What can this tool do?

Network visualization

Common uses

  • Move an existing GNPS2 network into desktop Cytoscape.

Scope and considerations

Designed for

  • GNPS2 network conversion with group styling and optional singletons.

Not designed for

  • Raw-data processing, network inference or validation of molecular identities.

Important requirements

  • Compatible GraphML or an accessible supported GNPS2 task.
  • Desktop Cytoscape to open the resulting session.

Considerations

  • Styling summarizes supplied groups; visual similarity is not chemical identification evidence.
  • Session compatibility should be checked with the installed Cytoscape version.

Access and documentation

Primary access↗

Public browser interface. The documented conversion runs locally in the browser; task-ID input fetches data from GNPS2. No independent execution test or software-license verification performed.
