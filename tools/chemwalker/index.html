Overview

ChemWalker combines molecular-network context with candidate structures evaluated by in-silico fragmentation. Its Python implementation uses MetFrag, while a GNPS2 workflow accepts a networking task and a selected molecular family. Propagated rankings guide annotation follow-up rather than confirming an identity.

What can this tool do?

In-silico spectrum prediction

Common uses

  • Prioritize candidate structures for unannotated members of a molecular family.
  • Combine candidate fragmentation evidence with neighboring library annotations.

Input formats

GNPS networking task ID and component index, Ion mode, adduct and optional pipe-separated candidate database

Output formats

Candidate annotation rankings from the selected network component.

Scope and considerations

Designed for

  • Annotation propagation within MS/MS molecular networks.

Not designed for

  • Raw feature detection, quantitative statistics or confirmed identification without additional evidence.

Important requirements

  • A compatible network task and selected molecular component; the GNPS2 form requests one component per run.
  • Appropriate ion/adduct settings and a candidate structure database; local installation requires the documented environment and MetFrag.

Considerations

  • Incorrect seed annotations and missing candidate structures can affect propagated rankings.
  • The repository reports testing with MetFrag 2.3; compatibility with newer dependencies was not execution-tested.
