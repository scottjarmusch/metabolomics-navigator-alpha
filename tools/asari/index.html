Overview

Asari uses mass alignment and a composite representation of chromatographic signals to extract features across samples. Its default workflow focuses on LC-MS feature processing.

What can this tool do?

Peak or feature detectionRetention-time alignment

Common uses

  • Build a feature table from centroided LC-MS files.
  • Prepare data for downstream quality control and statistics.

Scope and considerations

Designed for

  • Build a feature table from centroided LC-MS files.

Not designed for

  • Assigning confirmed chemical structures from feature detection alone.

Important requirements

  • Centroided mzML data and a compatible Python environment.

Considerations

  • Check mass tolerances, chromatography and acquisition mode against the workflow; default processing and specialized workflows differ.
