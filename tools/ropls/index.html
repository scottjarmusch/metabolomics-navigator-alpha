Overview

ropls provides scores, loadings, component assessment, permutation tests and variable-importance measures for exploratory and supervised analysis.

What can this tool do?

Multivariate statisticsFeature selection

Common uses

  • Explore sample patterns with PCA.
  • Evaluate supervised models with validation and permutation testing.

Scientific fit

Primary function

Statistical analysis

Data compatibility

Inputs

Feature or peak table, Sample metadata

Outputs

Statistical results, Human-readable report

Input formats

Other, Numeric matrix and optional response vector

Output formats

Other, PCA/PLS/OPLS models, statistics and plots

Scope and considerations

Designed for

  • Explore sample patterns with PCA.

Not designed for

  • Proving predictive performance from separation in a training-set scores plot.

Important requirements

  • A numeric measurement matrix and appropriate responses for supervised models.

Considerations

  • Avoid information leakage during preprocessing and feature selection; use independent validation when assessing generalization.
