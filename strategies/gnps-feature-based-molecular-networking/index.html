What does this strategy enable?

Feature-Based Molecular Networking connects an aligned chromatographic feature table to a network of representative fragmentation spectra. Unlike spectrum-centric networking, it retains feature-level abundance and can keep chromatographically separated isomers distinct. The Strategy is the analytical design; the GNPS2 FBMN workflow is one software implementation, used with compatible upstream feature-processing tools.

Transferable workflow

Workflow

  1. 1

    Process LC-MS/MS data into aligned features

    Perform feature detection, chromatogram construction/resolution, alignment, filtering, and MS/MS association in a compatible processing tool.

    MZmineMS-DIALxcmsOpenMS
  2. 2

    Export FBMN inputs

    Export a feature quantification table and representative MS/MS spectra using the selected implementation's supported format. Match feature identifiers between files and supply sample metadata when comparing groups.

    MZmineMS-DIALxcmsOpenMS
  3. 3

    Run the FBMN workflow in GNPS2

    Upload or select the feature table and spectral summary, configure tolerances and networking filters, and launch Feature-Based Molecular Networking.

    GNPS2 Feature-Based Molecular Networking workflow
  4. 4

    Overlay spectral-library annotations

    Search compatible nodes against GNPS spectral libraries and inspect molecular families containing annotated and unannotated features.

    GNPS2 Feature-Based Molecular Networking workflow
  5. 5

    Interpret quantitative molecular families

    Use feature abundances, metadata, retention time, ion mobility where available, and spectral relationships to compare molecular families across samples or conditions.

    Cytoscape

Adaptation · Briefings in Bioinformatics · 2024

Integrative open workflow for confident annotation and molecular networking of metabolomics MSE/DIA data

DIA-IntOpenStream adapts FBMN to MSE/DIA data. Waters2mzML supplies mzML; KNIME assembles custom structure databases; MS-DIAL assigns DIA fragments to precursors and exports FBMN inputs for GNPS and Cytoscape. MZmine 3 is used for a parallel MS1 annotation branch, not DIA fragment deconvolution in this study. Reliable precursor-fragment assignment is required; custom mass matches and network neighbors are not confirmed structures. The demonstrated conversion uses Windows and Waters data; other vendor compatibility is not established here.

Navigator tools used: MS-DIAL, MZmine, GNPS, Cytoscape

Scope and considerations

Designed for

  • Untargeted LC-MS/MS studies where chromatographic feature detection and quantitative feature tables are important for molecular-network interpretation.
  • Resolving isomeric or chromatographically separated features that would otherwise be combined in purely spectrum-centric networking.

Important requirements

  • An aligned feature quantification table and representative MS/MS spectra exported from a compatible preprocessing workflow.
  • Consistent feature identifiers across the quantification table and spectral export; raw files alone are not ready-to-use FBMN inputs.

Considerations

  • The quality of the molecular network depends on upstream feature detection, alignment, MS/MS assignment, and preprocessing choices.
  • FBMN does not remove the need for independent structural validation; library matches and network propagation represent different levels of annotation evidence.
