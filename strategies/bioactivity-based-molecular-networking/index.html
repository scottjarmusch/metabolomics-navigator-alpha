What does this strategy enable?

Bioactivity-Based Molecular Networking adds an orthogonal biological evidence layer to molecular networking. Fractionated samples are profiled by LC-MS/MS and tested in a quantitative bioassay. Feature abundances across fractions are correlated with bioactivity, producing a bioactivity score that is mapped onto the molecular network. This allows active molecular families and candidate analogues to be prioritized before isolation while preserving molecular-network annotation and dereplication context.

Transferable workflow

Workflow

  1. 1

    Generate fractions and quantitative bioassay data

    Fractionate the bioactive extract or sample set and measure a quantitative biological response for the same fractions used for metabolomics.

  2. 2

    Acquire untargeted LC-MS/MS profiles

    Profile the fractions by LC-MS/MS so that feature abundance across fractions and fragmentation spectra are available.

  3. 3

    Detect and quantify features

    Process the LC-MS/MS data to generate aligned feature intensities across the fraction series.

    MZmineOpenMS
  4. 4

    Calculate feature–bioactivity associations

    Correlate feature abundance across fractions with the quantitative bioassay response to calculate a bioactivity score for each feature.

    Bioactive Molecular Networks Jupyter workflow ↗
  5. 5

    Build and annotate the molecular network

    Generate a molecular network from MS/MS similarity and attach the bioactivity scores as node attributes so active molecular families can be recognized in chemical context.

    GNPS
  6. 6

    Prioritize and validate active chemistry

    Select high-scoring features or molecular families for isolation, orthogonal structural work, and direct activity confirmation.

Scope and considerations

Designed for

  • Bioassay-guided natural-product discovery where the same fractions or samples have quantitative LC-MS feature data and biological activity measurements.
  • Prioritizing active analogues within molecular families before purification.

Important requirements

  • Reproducible quantitative bioassay values matched to metabolomics samples.
  • Sufficient variation in both feature abundance and bioactivity across the sample or fraction series.
  • The supplied implementation uses MZmine 2 or Optimus exports and an R script or R-kernel Jupyter notebook; check current export compatibility.

Considerations

  • Correlation between a feature and bioactivity is prioritization evidence, not proof that the feature causes the phenotype.
  • Coeluting or covarying metabolites can receive similar activity scores and require follow-up isolation or orthogonal validation.
